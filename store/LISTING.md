## 説明（日本語）

Outlook on the web では、差出人の「表示名」しか見えず、メールアドレスはマウスを乗せないと確認できません。しかもこれは設定では変えられない仕様です。

「差出人アドレス表示 for Outlook」は、差出人名のすぐ横にメールアドレスを常に表示します。

■ 主な機能
・開いたメールの差出人名の横に、メールアドレスを常に表示
・メール一覧（受信トレイの各行）にも表示可能（ポップアップでON/OFF）
・ドメイン部分（@以降）を太字で表示し、なりすましメールに気づきやすく
・アドレスをクリックするとコピー

■ こんな方に
・表示名だけでは誰からのメールか判別しづらい
・社長や取引先の名前を騙ったなりすまし・フィッシングメールが心配
・アドレスを確認・コピーするたびにホバーするのが面倒

■ 対応
outlook.office.com / outlook.office365.com / outlook.live.com / outlook.cloud.microsoft

■ プライバシー
データの収集・送信は一切行いません。外部通信もありません。保存するのは表示のON/OFF設定のみです。

※ Microsoft および Outlook は Microsoft Corporation の商標です。本拡張機能は Microsoft とは無関係の非公式ツールです。

## Description (English)

Outlook on the web only shows the sender's display name — you have to hover over it to see the actual email address, and there is no setting to change that.

Sender Address Viewer for Outlook always shows the email address right next to the sender's name.

Features
• Always shows the sender's email address next to their name in the opened message
• Optionally shows addresses in the message list too (toggle in the popup)
• The domain (after @) is shown in bold, so spoofed senders stand out
• Click an address to copy it

Great if you
• Can't tell who sent an email from the display name alone
• Worry about phishing emails that impersonate your boss or business partners
• Are tired of hovering every time you want to check or copy an address

Supported
outlook.office.com / outlook.office365.com / outlook.live.com / outlook.cloud.microsoft

Privacy
No data is collected or sent anywhere. No network requests. Only your on/off display settings are stored.

Microsoft and Outlook are trademarks of Microsoft Corporation. This extension is an unofficial tool and is not affiliated with Microsoft.

## プライバシー（審査フォーム）

### 単一用途の説明 / Single purpose
Outlook on the web で、差出人の表示名の横にその差出人のメールアドレスを常に表示すること。
Display the sender's email address next to the sender's display name in Outlook on the web.

### storage 権限の理由
表示のON/OFF設定（開いたメール・メール一覧）を保存するためにのみ使用します。
Used only to save the user's on/off display settings (opened message / message list).

### ホスト権限（コンテンツスクリプト）の理由
Outlook on the web のページ上で差出人のメールアドレスを読み取り、同じページ上に表示するために、Outlook のドメインでのみコンテンツスクリプトを実行します。読み取ったデータは外部に送信しません。
Content scripts run only on Outlook on the web domains to read the sender's address on the page and display it on the same page. Nothing is sent externally.

### リモートコード
使用していません / No remote code.

### データ使用
収集するデータ: なし（すべてのチェックボックスを未選択）
- 販売・転送しない / 用途外で使用しない / 信用力判断に使用しない に同意
